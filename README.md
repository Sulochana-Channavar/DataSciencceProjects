# Data Science Projects

A comprehensive repository housing machine learning, data analysis, and predictive modeling projects completed during the **CodeAlpha Data Science Internship**.

##  Repository Overview
This repository contains end-to-end implementations of key data science tasks, covering classification, exploratory data analysis (EDA), and regression techniques.

| Notebook | Domain | Task Description |
| :--- | :--- | :--- |
| `IrisFlowerClassification.ipynb` | Supervised Learning | Classifying iris flower species using morphological features |
| `UnemploymentAnalysis.ipynb` | Exploratory Data Analysis | Analyzing regional unemployment trends and COVID-19 impact |
| `CarPricePrediction.ipynb` | Machine Learning (Regression) | Predicting used vehicle selling prices based on market features |

##  Project Summaries

### 1. Iris Flower Classification (`IrisFlowerClassification.ipynb`)
* **Objective:** Classify Iris flowers into three species (*Setosa*, *Versicolor*, *Virginica*) based on sepal and petal dimensions.
* **Techniques:** Feature scaling, train-test splitting, Random Forest Classifier, and confusion matrix evaluation.
* **Key Outcome:** High-accuracy multi-class categorization demonstrating foundational classification workflows.

### 2. Unemployment Analysis with Python (`UnemploymentAnalysis.ipynb`)
* **Objective:** Analyze historical unemployment rate patterns across regions and assess the economic shock during the COVID-19 pandemic.
* **Techniques:** Data cleaning, date-time formatting, timeline trend analysis, and regional correlation heatmaps.
* **Key Outcome:** Visualized the sharp unemployment spike during the 2020 lockdown periods and identified state-wise variance.

### 3. Car Price Prediction with Machine Learning (`CarPricePrediction.ipynb`)
* **Objective:** Predict resale values of pre-owned cars using features like showroom price, distance driven, fuel type, and transmission.
* **Techniques:** Feature engineering (deriving vehicle age), One-Hot Encoding for categorical variables, and Random Forest Regression.
* **Key Outcome:** Identified present showroom price and vehicle age as the primary drivers of automotive depreciation.
